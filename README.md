# Installation
This project is built using native web technologies (HTML5, CSS3, Vanilla JS, WebGL via Three.js) and requires no compilation, build steps, or package installations.

Clone or open the project folder:

bash

git clone https://github.com/Elbin369/Doomskart.git
cd Doomskart

# Run
Because modern browsers require a local HTTP server to load JavaScript ES6 modules and WebGL textures, run any of the following commands:

Option A — Using Python (Recommended):
bash
python -m http.server 8000

Option B — Using Node.js:
bash
npx serve . -l 8000

Option C — Using PHP:
bash
php -S localhost:8000
Open in Browser:

3D Solar System (Main App): http://localhost:8000
Planet Marketplace: http://localhost:8000/Doomskart%20Shop/index.html
Payment & Ownership Portal: http://localhost:8000/Doomskart%20Payment/payment-form.html
